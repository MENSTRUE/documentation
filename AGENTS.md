# AGENTS — Aturan Pengelolaan Repository Documentation

- Tujuan: standar dokumentasi dan pemulihan **lintas proyek**, berbahasa Indonesia.
- Jangan mengasumsikan template berlaku mentah-mentah untuk semua stack.
- Audit kode, README, konfigurasi, notebook, output eksperimen, dan aset sebelum menulis klaim.
- Utamakan file/fakta aktual; jika bukti tidak ada, tulis **Belum diverifikasi**.
- Pertahankan konten benar dari versi sebelumnya; periksa Git diff sebelum overwrite.
- Jangan simpan secret, password, API token, data sensitif, dataset privat, atau checkpoint proprietary dalam repo template.
- Jika memublikasikan model, periksa lisensi, ukuran dan tata cara release, SHA-256, class mapping, dependency, preprocessing.
- Bedakan source code, model weights, training data, metadata, cache, dan output turunan.
- Penyajian metrik wajib memuat provenance, split, definisi metrik, jumlah sampel dan keterbatasan.
- Tautan antar-Markdown dan file visual harus benar-benar ada.
- Setiap perubahan standar harus menyertakan alasan dan contoh penggunaan.
- Tidak melakukan push, menghapus, atau mempublikasikan aset pengguna tanpa permintaan yang jelas.
